Dashboard de evaluación PSM - BDH Ecuador

Interfaz de visualización para el análisis de Propensity Score Matching (PSM) aplicado al Bono de Desarrollo Humano. Esta vista presenta el soporte común del puntaje de propensión estimado y la comparación de ingresos antes y después del emparejamiento.

Distribución del Propensity Score

Gráfico de densidad construido a partir del puntaje de propensión estimado con variables observables previas al tratamiento. El soporte común identifica el rango de puntajes donde conviven tratados y controles.

Comparación de ingresos

Comparación de ingresos promedio antes y después del emparejamiento. Este gráfico ilustra la reducción de brechas y el contrafactual construido con nearest neighbor matching.

Notas metodológicas

El cálculo del Propensity Score se realiza con una especificación de regresión logística utilizando covariables previas al tratamiento. El emparejamiento se define según nearest neighbor para construir un contrafactual de control comparable.

Fuentes de datos y procesamiento econométrico

Los gráficos se cargan desde `src/dashboard/datos_reales_psm.json` y calculan el soporte común y la comparación de ingresos con los datos empíricos procesados del ENEMDU 2024. Si el JSON aún no está disponible, el dashboard usa una tabla de respaldo de ejemplo mientras se completa la exportación de los datos reales.
